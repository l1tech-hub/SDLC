## Описание проекта
Программа «Идеальное похудение» предназначена для расчёта целевого пульса во время кардиотренировок на велотренажёре, степ-тренажёре, гребном тренажёре и эллипсоиде.
Пользователь вводит возраст и пульс в состоянии покоя. На основе формулы Карвонена приложение рассчитывает рекомендуемый диапазон пульса для тренировок, отображает начальный целевой пульс и ориентир для последующих занятий.
Приложение предусматривает ввод данных в отдельной форме, проверку корректности введённых значений и сохранение последних введённых данных для повторного использования.

- Сохранение состояния: запоминание последних введенных данных и их автоматическое восстановление при повторном открытии диалога.
- Валидация: проверка корректности введенных данных и вывод сообщений при ошибках.
- Архитектура: реализация логики на основе паттерна MVC с активной моделью (Model-View-Controller)
