## Описание проекта

Приложение предназначено для автоматизированного учёта продуктов и готовых блюд кафе с использованием базы данных.

Основные возможности:

* Учёт продуктов, поиск по названию и выбор из списка.
* Добавление новых продуктов через отдельное окно.
* Отображение изображений продуктов и готовых блюд.
* Хранение рецептов приготовления с указанием ингредиентов в граммах.
* Просмотр текстового рецепта приготовления каждого блюда.

Проект позволит упростить управление продуктами и блюдами кафе, а также обеспечить удобный доступ к информации об ингредиентах и способах приготовления.
